## Frontend Coding Standards

This is a list of coding standards that we want developers to adhere to. 
Check for examples based on the coding standard id eg. EX1 in the examples directory eg. examples/EX1.md


EX0: use snakecase for function, variables and css selectors
EX1: render should avoid array as parent element instead have a single dom element.
EX2: consider refactoring render when dom markup or business logic grows in render and especially in a View.
EX3: if statements should avoid inline business logic or complex nesting.
EX4: components functions and naming should be based context and convention
EX5: common naming conventions for function, variables, classes
EX6: avoid maps and instead use for statements
EX7: standards for the app.coffee
EX8: Don't use global constants
